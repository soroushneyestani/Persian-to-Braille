# Persian-to-Braille — Windows Desktop Release Package

This package contains the Windows Desktop release-candidate assets for the
Persian-to-Braille Microsoft 365 add-in.

Release scope:

```text
Microsoft Word for Microsoft 365 Desktop on Windows
Microsoft Excel for Microsoft 365 Desktop on Windows
Microsoft PowerPoint for Microsoft 365 Desktop on Windows
```

This package is not Microsoft certification and is not Microsoft Marketplace
publication.

## Quick installation

1. Run `Persian-to-Braille-Windows-Preview-Installer.cmd`.
2. Allow the Windows UAC prompt if it appears.
3. Close and reopen Word, Excel, or PowerPoint when requested.
4. Open `Home -> Add-ins -> Get Add-ins / Advanced -> SHARED FOLDER`.
5. Select `Persian-to-Braille`.
6. Choose `Add`.
7. Select Persian text and use `Translate Selection`.

## راهنمای سریع فارسی

1. فایل `Persian-to-Braille-Windows-Preview-Installer.cmd` را اجرا کنید.
2. اگر پنجره UAC نمایش داده شد، اجازه ادامه بدهید.
3. Word، Excel یا PowerPoint را دوباره باز کنید.
4. مسیر `Add-ins -> Get Add-ins / Advanced -> SHARED FOLDER` را باز کنید.
5. `Persian-to-Braille` را انتخاب کنید.
6. روی `Add` بزنید.
7. متن فارسی را انتخاب کرده و `Translate Selection` را اجرا کنید.
