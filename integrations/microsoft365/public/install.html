Persian-to-Braille

Manual Preview Installation

Persian-to-Braille is not currently published through Microsoft Marketplace. This page provides a manual preview distribution channel for users and organizations that want to evaluate the Microsoft 365 add-in before Marketplace publication is available.

Windows Desktop Preview

For Microsoft 365 Desktop on Windows, the preview installer prepares the same local network-share catalog and trusted Office add-in catalog used by the verified Windows sideload flow.

Download Windows Desktop Preview Installer

The installer downloads the production manifest over HTTPS, creates a local add-in catalog, registers that catalog for the current Windows user, and then opens Word. Windows may show a UAC prompt because creating the local SMB share requires elevated permission. The installer never installs a separate Braille engine inside Office: the add-in still uses the hosted Microsoft365 → SDK → Core runtime.

This is a Windows sideload/testing convenience. It is not Microsoft Marketplace publication. Microsoft documents network-share deployment as a testing mechanism and states that it is not supported for production add-ins.

راهنمای نصب نسخه دسکتاپ ویندوز

ابتدا فایل Windows Desktop Preview Installer را دانلود و اجرا کنید. نصب‌کننده فایل Manifest نسخه production پروژه را از آدرس HTTPS پروژه دریافت می‌کند و تنظیمات لازم برای نمایش افزونه در Microsoft Word، Excel و PowerPoint را انجام می‌دهد.

اگر Word، Excel یا PowerPoint باز باشد، نصب‌کننده از شما می‌خواهد ابتدا برنامه‌های Office را ببندید تا فایل‌های ذخیره‌نشده به‌صورت ناخواسته بسته نشوند. در صورت نمایش پنجره UAC ویندوز، اجازه ادامه نصب را بدهید.

  1. پس از پایان نصب، Microsoft Word، Excel یا PowerPoint را باز کنید.
  2. از نوار بالای Office روی Add-ins کلیک کنید.
  3. در پنجره کوچک بازشده روی Get Add-ins کلیک کنید. در بعضی نسخه‌های Microsoft 365 همین گزینه با عنوان Advanced نمایش داده می‌شود.
  4. در پنجره Office Add-ins وارد تب SHARED FOLDER شوید.
  5. گزینه Persian-to-Braille را انتخاب کنید.
  6. روی Add کلیک کنید.
  7. اکنون دکمه Translate Selection در Ribbon برنامه در دسترس است.
  8. متن فارسی را انتخاب کنید، روی Translate Selection بزنید و نتیجه Braille را در Task Pane مشاهده کنید.

این روش برای نسخه پیش‌نمایش و آزمایش روی Windows Desktop است و به معنی انتشار افزونه در Microsoft Marketplace نیست.

Windows setup steps

  1. Download and run the Windows Desktop Preview Installer.
  2. Allow the Windows UAC prompt if it appears.
  3. Close and reopen Word, Excel, or PowerPoint after setup.
  4. Select Home → Add-ins.
  5. Choose Get Add-ins, or Advanced when that label is shown.
  6. Open the SHARED FOLDER tab.
  7. Select Persian-to-Braille.
  8. Choose Add.
  9. Use Translate Selection from the ribbon.

Braille Music from MIDI — Word Desktop / Windows

Braille Music has been live verified in Microsoft Word Desktop on Windows. Standard MIDI files with a .mid or .midi extension are read locally by the add-in.

  1. Open the add-in in Microsoft Word Desktop on Windows.
  2. Select the Music / MIDI tab.
  3. Choose a Standard MIDI file.
  4. Choose exactly one MIDI line. A line is one Track + Channel pair.
  5. Select Preview Music Braille to generate Unicode Music Braille and BRF / Braille ASCII.
  6. Select Insert Music Braille to insert the exact successful preview at the current Word caret or selection.

No notes inside the selected line are automatically removed based on instrument, percussion, program, or channel classification.

Some complex MIDI lines may not yet be representable by the current notation bridge. Those lines fail explicitly instead of silently deleting or simplifying musical material. Choose another source line when appropriate.

Whole-song multi-line / All Lines conversion is not exposed in this preview.

Individual preview — Office on the web

  1. Download the manifest from this page.
  2. Open Word, Excel, or PowerPoint in Office on the web.
  3. Open a document or presentation.
  4. Select Home → Add-ins → More Settings.
  5. Select Upload My Add-in.
  6. Choose the downloaded manifest XML file and upload it.

Microsoft documents this flow as sideloading for development and testing. A web-sideloaded manifest is stored in the browser's local storage, so clearing browser data or switching browsers can require sideloading it again.

Organization deployment — Microsoft 365 admin

Microsoft 365 administrators can centrally deploy an add-in-only manifest to supported users and groups through the Microsoft 365 admin center.

  1. Open the Microsoft 365 admin center.
  2. Go to Settings → Integrated apps.
  3. Open the Add-ins deployment flow.
  4. Choose the custom add-in option.
  5. Upload the downloaded manifest, or provide the stable manifest URL shown above when the tenant UI offers URL-based manifest upload.
  6. Assign the add-in to the intended users or groups.

Mac preview

Microsoft also documents manual manifest sideloading on Mac for testing. The manifest is copied into the Office application's wef folder and the host application is restarted. Refer to Microsoft's current sideloading documentation for the host-specific folder path.

Windows desktop note

The Windows Desktop Preview Installer automates preparation of a local network-share catalog for sideload testing. Microsoft documents network-share deployment as a testing mechanism and states that it is not supported for production add-ins.
