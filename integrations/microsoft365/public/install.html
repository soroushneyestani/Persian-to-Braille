Persian-to-Braille

Manual Preview Installation

Persian-to-Braille is not currently published through Microsoft Marketplace. This page provides a manual preview distribution channel for users and organizations that want to evaluate the Microsoft 365 add-in before Marketplace publication is available.

Individual preview — Office on the web

  1. Download the manifest from this page.
  2. Open Word, Excel, or PowerPoint in Office on the web.
  3. Open a document or presentation.
  4. Select Home → Add-ins → More Settings.
  5. Select Upload My Add-in.
  6. Choose the downloaded manifest XML file and upload it.

Microsoft documents this flow as sideloading for development and testing. A web-sideloaded manifest is stored in the browser's local storage, so clearing browser data or switching browsers can require sideloading it again.

Organization deployment — Microsoft 365 admin

Microsoft 365 administrators can centrally deploy an add-in-only manifest to supported users and groups through the Microsoft 365 admin center.

  1. Open the Microsoft 365 admin center.
  2. Go to Settings → Integrated apps.
  3. Open the Add-ins deployment flow.
  4. Choose the custom add-in option.
  5. Upload the downloaded manifest, or provide the stable manifest URL shown above when the tenant UI offers URL-based manifest upload.
  6. Assign the add-in to the intended users or groups.

Mac preview

Microsoft also documents manual manifest sideloading on Mac for testing. The manifest is copied into the Office application's wef folder and the host application is restarted. Refer to Microsoft's current sideloading documentation for the host-specific folder path.

Windows desktop note

A Windows network-share catalog is not presented here as a public installation method. Microsoft documents network-share deployment as a testing mechanism and states that it is not supported for production add-ins.
