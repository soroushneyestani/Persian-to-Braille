What the add-in does

Braille Hub translates supported text selections and provides Braille Music workflows in Unicode Braille through the project's shared public SDK and Core.

Supported Office workflows

  • Word: translate selected text, copy Braille, replace the selection, or insert the Braille result after the selection.
  • Excel: translate exactly one selected plain-text cell, copy Braille, or replace that cell.
  • PowerPoint: translate selected text, copy Braille, or replace the selected text.

Before reporting a problem

  1. Confirm that the add-in task pane opens in a supported Office host.
  2. Make a supported selection before choosing Translate Selection.
  3. For Excel, use one plain-text cell. Multi-cell selections and formula cells are intentionally rejected.
  4. If the document selection changed after preview, translate again before replacing it.
