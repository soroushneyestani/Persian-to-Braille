Braille Hub for Microsoft 365

Privacy Policy

This policy describes the data-handling behavior of the Braille Hub Microsoft 365 Add-in.

Support Privacy EULA

Scope

This Privacy Policy applies to the Braille Hub add-in for Microsoft Word, Excel, and PowerPoint published by Soroush Neyestani.

Office content processed by the add-in

When you explicitly request a translation, the add-in reads the currently supported Office selection needed to perform that operation. The selected content is processed locally through the Braille Hub translation architecture and Core within the add-in's client-side runtime to produce a Braille preview.

The add-in writes a Braille result back to the Office document only when you explicitly choose a supported write action such as Replace Selection or, in Word, Insert After.

Application-owned collection and storage

In the audited release, the add-in does not implement its own account system, authentication service, advertising system, analytics SDK, or telemetry SDK.

The add-in does not implement application-owned persistence of selected Office content through localStorage, sessionStorage, IndexedDB, or application cookies.

The audited add-in runtime does not implement an application-owned fetch, XMLHttpRequest, WebSocket, or EventSource path that sends the selected Office content to a publisher-controlled server.

Clipboard actions

If you choose Copy Braille, the generated Braille result is written to the clipboard as a user-requested client-side action.

Microsoft and hosting infrastructure

The add-in runs inside Microsoft Office and loads the Microsoft Office JavaScript library from Microsoft's hosted Office.js content delivery network.

Production add-in web assets are served through GitHub Pages. Microsoft, GitHub, the browser, network providers, or the Office host may process ordinary technical request information as part of providing their platforms and network infrastructure. That infrastructure processing is separate from application-owned translation logic.

This policy does not make an absolute claim that no network request, platform log, or infrastructure metadata exists outside the add-in's own application logic.

Publisher-side retention

The audited release does not include a publisher-operated backend, database, or account service for retaining selected Office content. Accordingly, the add-in itself does not provide a publisher-side storage mechanism for translated selections.

Sale, advertising, and profiling

The audited release does not implement advertising, behavioral profiling, or an application-owned mechanism for selling user content or translation data.

Security and user responsibility

Avoid placing confidential or sensitive material in public support channels. Use Office and your device in accordance with your organization's security policies.

Changes to this policy

If the add-in later introduces a backend service, account system, analytics, telemetry, or other material data-processing behavior, this policy must be updated before that behavior is represented as covered by this version of the policy.

Privacy questions

Privacy questions can be initiated through the public support page. Do not post personal, confidential, or sensitive information in the public issue tracker.
