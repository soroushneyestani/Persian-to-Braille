# Braille Hub Branding

This directory contains the canonical visual identity assets for **Braille Hub**.

## Product identity

**Braille Hub**  
**Text & Music Accessibility**

## Assets

- `braille-hub-logo.png` — canonical full product lockup
- `braille-hub-symbol.png` — symbol-only transparent asset

- `build-icons.py` — reproducible Office icon generator

The Microsoft 365 integration consumes copies of the required runtime assets from:

`integrations/microsoft365/public/assets/`

The historical repository name, package namespace, specification identifiers, and legacy evidence remain unchanged during this rebrand and are intentionally migrated separately.
