[ARCHITECTURE CONSEQUENCES]
1. Reverse translation cannot be implemented as a global Braille-cell lookup table.
2. The reverse engine needs explicit parser state for numeric and Latin modes plus capitalization.
3. Numeric mode does not identify which print digit family (ASCII, Persian, Arabic-Indic) should be emitted; Phase 13 needs an explicit output policy.
4. Some punctuation/context collisions retain multiple print spellings after semantic context is known; they need a canonicalization or ambiguity policy.
5. 29 no-cell forward rules require an explicit reconstruction contract rather than blind inversion.
6. Multi-cell and sequence signatures require longest-match / segmentation rules.
7. Reverse conformance must be authored independently and should include ambiguity, state transitions, malformed Braille, and round-trip properties.
