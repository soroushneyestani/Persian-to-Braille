# Persian Braille Phase 1 Master Decision Matrix

Audit stage: **1.8**

This document consolidates the evidence datasets produced in Stages 1.2 through 1.7 into one de-duplicated decision matrix.

**This matrix is not the normative Persian Braille specification.** It is the gate between evidence collection and Phase 2 rule adoption.

## Decision classes

- **CONSENSUS-CANDIDATE** — no known evidence conflict for the proposed behavior, with institutional/manual evidence supporting the candidate.
- **REVIEW-REQUIRED** — evidence exists, but institutional validation, Unicode policy, host policy, or conflict resolution is still required.
- **UNRESOLVED** — the current evidence does not define a complete behavior suitable for promotion.

## Phase 2 admission rule

A `CONSENSUS-CANDIDATE` item is still not normative. Phase 2 must create an explicit rule record with a stable rule ID, profile scope, input/context definition, Braille output, evidence citations, rationale, and conformance vectors before the item becomes normative.

`REVIEW-REQUIRED` and `UNRESOLVED` items must not be silently copied from Liblouis, the draft pull request, or Persian-to-Braille v1.

Stage 1.8 completes evidence consolidation for the pinned Persian Grade-1 implementation baseline. The remaining work is decision-making and specification authoring, not further unstructured extraction.
